# Add third party repositories to Fedora Silverblue
A simple script for adding third party repositories to Fedora Silveblue.

## Usage
1. Clone the repository: `git@github.com:ottop/silverblue_add_repo.git`
2. Enter the directory: `cd silverblue_add_repo`
3. Give the script the permission to run: `chmod +x add_repo.sh`
4. Run the script: `./add_repo.sh https://website.url/filename.repo` (replace the example url with the actual url of the .repo file for a repository)
